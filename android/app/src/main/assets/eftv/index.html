Android

Rode a EFTV no seu celular

Com o Termux (app gratuito) o mesmo server.py roda no Android. Depois, a smart TV, o tablet ou o notebook acessam a EFTV pela rede Wi-Fi.

  1. Instale o Termux (F-Droid ou Google Play) e abra o app.
  2. Cole o comando abaixo no Termux e toque em Enter. Ele instala o Python, baixa a EFTV e sobe o servidor.
  3. Abra http://127.0.0.1:8124/ no Chrome do celular. Na smart TV, digite o endereço Na rede Wi-Fi mostrado no Termux e salve como favorito.
  4. Deixe o celular carregando e com o Termux aberto. Para o servidor continuar com a tela apagada, instale o addon Termux:API.
pkg install -y python git && git clone https://github.com/EvertonFagundes/eftv.git ~/eftv && bash ~/eftv/instalar/instalar-eftv-termux.sh

Depois de instalar, o Termux cria os comandos eftv (sobe o servidor), eftv-servidor (sobe sem abrir o navegador), eftv-parar (encerra) e eftv-atualizar (atualiza o código).

Se o git clone falhar porque a rede usa um espelho do GitHub fora do ar, baixe o pacote completo pelo navegador do celular e no Termux rode: pkg install -y unzip, unzip ~/eftv-android.zip -d ~ e bash ~/eftv/instalar/instalar-eftv-termux.sh.

Instalar a EFTV Tenha um atalho como um aplicativo.

No Chrome, Edge ou Android, toque em Instalar app e confirme. No iPhone/iPad, toque em Compartilhar e depois em Adicionar à Tela de Início.

O atalho abre a EFTV em tela cheia, com seus canais salvos neste dispositivo.
Instalar o lançador da EFTV Uma vez só. Depois é só clicar em Iniciar.

1. Baixe o instalador do seu sistema:

Windows (.bat) macOS e Linux (.sh)

2. Execute o arquivo baixado. Ele instala o Python (se faltar) e registra o protocolo eftv://, que é o que permite iniciar o servidor pela página.

3. Volte para esta página e clique em Iniciar servidor local. A aba http://127.0.0.1:8124/ abre sozinha.

Prefere fazer na mão? Clone o repositório, rode python3 server.py e recarregue esta página: o botão Abrir EFTV local aparece sozinho.
