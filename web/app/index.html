Ajuda

Como usar o EFTV na web

  • Abra eftv.com.br/app no navegador do celular.
  • Toque em “Instalar app” para criar um atalho na tela inicial.
  • Não é preciso baixar APK de fontes desconhecidas.
  • O plano permite 2 aparelhos e 1 tela simultânea.
  • Use a busca (sem acento) ou a barra A-Z para achar canais rapidamente.

Problemas comuns

  • “Limite de tela”: feche o player em outro aparelho ou aguarde 2 minutos.
  • Vídeo não abre: o provedor pode bloquear CORS; use o app Android nesse caso.
  • Sem som: toque no ícone de volume no player.
